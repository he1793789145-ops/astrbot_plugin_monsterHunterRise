# 在 QQ 官方机器人上使用

本文是 QQ 开放平台（`q.qq.com`）后台的配置清单，按顺序做一遍即可让插件在
官方机器人上跑起来。插件侧不需要任何额外配置——检测到平台是
`qq_official` / `qq_official_webhook` 时会自动切换发送方式。

> 说明：官方机器人**只能群聊**（本插件范围），且必须被 `@` 才会触发。
> 频道与私聊不在本插件的验证范围内。

---

## 一、开放平台后台

打开 <https://q.qq.com/qqbot/dashboard>，选中你的机器人。

### 1. 开发设置

| 项目 | 取值 | 备注 |
|---|---|---|
| 机器人 AppID | 形如 `102xxxxxx` | 填到 AstrBot 的 `appid` |
| AppSecret | 重置后只显示一次 | 填到 AstrBot 的 `secret`；**Token 字段已废弃，不用填** |
| 事件订阅方式 | **WebSocket** | 选 Webhook 的话在 AstrBot 里改用 `qq_official_webhook` 适配器 |
| IP 白名单 | 填运行 AstrBot 那台机器的公网 IP | 不填会让连接被拒 |

AppSecret 泄露等于机器人被接管，不要贴进聊天记录或提交到仓库。

### 2. 服务范围（沙箱配置）

个人认证开发者的四个开关默认全关，需要按用途打开：

| 开关 | 本插件是否必需 | 说明 |
|---|---|---|
| 群聊 →「允许添加到任意群聊（提供公开服务）」 | 建议开 | 不开的话只能加自己是群主/管理员的群（上限 2000 个） |
| 好友（私聊） | 不需要 | 本插件不做私聊 |
| 频道 | 不需要 | 本插件不做频道 |
| 允许被搜索到 | 可选 | 只是让别人能搜到机器人 |

### 3. 隐私协议

**必须提交**，否则机器人无法对外提供服务（后台会一直显示未提交/未通过）。
这是表单填写，只能由账号持有人自己完成。

### 4. 开发体验号码

若不想走公开服务审核，可以在后台加「开发体验号码」（默认 20 个名额）：
把这些 QQ 号加进白名单后，它们所在的群可以直接用机器人。
适合自己小范围试跑。

### 5. 菜单与指令（可选，纯体验优化）

官方客户端会给机器人显示一个「指令」面板，需要在这里配置才会出现。
本插件的指令都是 `/mh` 加子命令，**面板不是必需的**——不配也能正常用，
只是用户得自己记住 `/mh 素材 龙玉` 的写法。

要配的话，建议只放最常用的几条（面板里条目太多反而没人看）：

| 指令名 | 说明 | 示例 |
|---|---|---|
| `mh` | 怪物猎人素材查询 | `/mh help` |
| `mh 素材` | 查素材获取方式 | `/mh 素材 龙玉` |
| `mh 怪物` | 查怪物弱点与掉落 | `/mh 怪物 爵银龙` |
| `mh 肉质` | 查分部位肉质 | `/mh 肉质 爵银龙` |
| `mh 武器` | 查武器做法与详情 | `/mh 武器 伞鸟枪` |

> 后台的「指令名」通常不带斜杠，实际发送时用户仍需带 `/mh` 前缀。

### 6. 功能介绍图

可选。不上传不影响功能，只是机器人的资料页会空着。

## 二、AstrBot 侧

在 AstrBot 面板「消息平台」里新增 **QQ 官方机器人（WebSocket）**：

| 配置项 | 填什么 |
|---|---|
| `id` | 随便起个唯一标识，例如 `qqbot` |
| `enable` | 开 |
| `appid` | 后台的 AppID |
| `secret` | 后台的 AppSecret |
| `enable_group_c2c` | 开（群聊要用） |
| `enable_guild_direct_message` | 关（本插件不做频道/私聊） |
| `use_markdown` | **建议关** |

`use_markdown` 关掉更稳：插件在官方平台的纯文本回复已经显式按纯文本发送，
不依赖这个开关；但如果开了它，其它插件的纯文本回复会走 Markdown 模板校验，
一旦模板没配好就会报错回退，徒增噪音。

装好插件、填好配置后重载插件即生效。

## 三、验证

在群里 `@机器人 /mh 素材 龙玉`，应当收到一张卡片。

如果有问题，按这个顺序看：

| 现象 | 原因 | 处理 |
|---|---|---|
| 完全没反应 | 没 `@` 机器人，或 `appid`/`secret` 错，或 IP 不在白名单 | 看 AstrBot 日志里有没有连接失败 |
| 回了「没有查到结果」以外的纯文本 | 数据快照没生成 | 按 README「重新生成快照」跑一遍 |
| 只收到文字、没有图 | 卡片渲染失败，走了降级摘要 | 日志里搜 `卡片渲染失败`，看具体异常 |
| 收到图但文字没了 | 与预期不符，提 issue | 附上 AstrBot 版本与日志 |

插件在官方平台的降级是**有提示的**：摘要末尾会写「图片发送失败，以上为摘要」，
不会静默少东西。

## 四、与 OneBot 的差异

| 项目 | OneBot v11 | QQ 官方机器人 |
|---|---|---|
| 触发方式 | `/mh ...` 即可 | **必须 `@机器人`** |
| 文本与图片 | 两条消息 | 合并成一条 |
| 纯文本的 Markdown | 跟随平台配置 | 强制关闭 |
| 图片失败 | 回退全文纯文本 | 回退摘要（≤800 字） |
| 频道 | 支持（依赖实现） | 本插件不覆盖 |

两套平台可以同时启用，插件会自己判断当前是哪个。
